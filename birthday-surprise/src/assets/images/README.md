# Local Memory Images

Drop your custom photos here to replace the default online images!

Example filenames to put here:
- `memory1.jpg`
- `memory2.jpg`
- `memory3.jpg`
- `memory4.jpg`
- `memory5.jpg`

To use local images in `src/data/memories.js` or `src/components/PhotoGallery.jsx`:

```js
import memory1 from '../assets/images/memory1.jpg';
// set image property to memory1
```
