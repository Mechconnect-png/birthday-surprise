# Custom Birthday Audio File

Place your favorite romantic background track here!

Target File Path:
`public/music/birthday-song.mp3`

Supported formats:
- MP3 (`.mp3`)
- WAV (`.wav`)
- AAC / M4A (`.m4a`)

The website automatically includes a built-in soft ambient web synth tune as a fallback if `birthday-song.mp3` is not provided!
